# GPADS CodePath Frontend

React + Vite. Dashboard, ranking, relatórios quinzenais, avaliação e publicação por líderes, perfil e 12 avatares pixel art selecionáveis. Admins e avaliadores cadastram estudantes e admins; líderes cadastram estudantes de suas células.

## Desenvolvimento

Node.js >=22.12.0. Copie .env.example para .env e configure Firebase e a URL da API.

- npm ci
- npm run dev
- npm run build
- npm run lint

[DEPLOY.md](DEPLOY.md) contém o passo a passo de Vercel, Render e Firebase. A chave Gemini e o token GitHub pertencem apenas ao backend.
